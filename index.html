快捷鍵以 Windows 版 Microsoft 365 / Excel 2021 為準。實戰練習請先切換成英文輸入法，否則注音輸入法會攔下按鍵。

少數組合鍵（例如 Ctrl+N、Ctrl+W、Ctrl+PageDown）會被瀏覽器搶先處理，這些題目會自動改成選擇題。

手機使用：iPhone 用 Safari 開啟後按「分享 → 加入主畫面」；Android 用 Chrome 開啟後按右上角「⋮ → 加到主畫面」。加入後就像 App 一樣，打開過一次之後沒有網路也能用。
